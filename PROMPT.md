# Промпт для создания Dark Dashboard

Этот файл содержит детальный промпт (запрос), с помощью которого можно сгенерировать проект, аналогичный моему.

## Основной Промпт:

> **Роль:** Ты — Senior Frontend-разработчик и эксперт по UI/UX дизайну.
> 
> **Задача:** Напиши код для одностраничного веб-приложения (SPA) — дашборда в стиле Gothic / Dark Wave. Используй чистый HTML, CSS и Vanilla JavaScript. Код должен быть строго разделен на три файла: `index.html`, `style.css` и `script.js`.
> 
> **Общий стиль (Дизайн):**
> *   Фон: глубокий черный (`#050505`) с легким радиальным градиентом по краям.
> *   Акцентные цвета: цвет запекшейся крови (`#8b0000`) и холодный серебристый (`#e0e0e0`, `#a3a3a3`).
> *   Шрифты: 'Cinzel' (для заголовков) и 'Montserrat' (для основного текста).
> *   Сетка: Использовать CSS Grid. На компьютере — две колонки. На мобильных (медиа-запросы) — одна колонка с определенным порядком карточек (Погода -> Время -> Валюты -> Крипта -> Статус).
> 
> **Функционал (5 карточек):**
> 
> 1.  **Погода:**
>     *   Поле ввода города (с автодополнением через тег `datalist` для популярных городов) и кнопка «Найти».
>     *   Запрос к API `wttr.in` (город передается в URL).
>     *   Вывод температуры, иконки (строгие символы вроде ☀, ☁, ☂), и переведенного на русский язык описания погоды.
> 2.  **Валюты:**
>     *   Выпадающий список валют (USD, EUR, CNY, GBP, JPY).
>     *   Запрос к API ЦБ РФ (`cbr-xml-daily.ru/daily_json.js`).
>     *   Вывод текущего курса и изменения за день в процентах (зеленый цвет для роста, красный для падения).
> 3.  **Криптовалюты:**
>     *   Выпадающий список монет (BTC, ETH, DOGE, SOL).
>     *   Запрос к API `CoinLore` (не требует прокси).
>     *   Вывод цены в долларах и автоматическая конвертация в рубли по текущему курсу ЦБ (курс берется из запроса валют).
> 4.  **Мировое время:**
>     *   Вывод времени в Москве, Лондоне и Токио с обновлением каждую секунду (использовать `toLocaleTimeString`).
> 5.  **Статус системы (Имитация):**
>     *   Реальный Uptime (время с момента загрузки страницы).
>     *   Вывод потребления памяти браузера (через `performance.memory` с проверкой на поддержку).
>     *   Случайно меняющийся пинг и уровень угрозы (HIGH/LOW).
> 
> **Дополнительные требования:**
> *   Использовать `localStorage` для сохранения последнего выбранного города, валюты и криптовалюты. При перезагрузке страницы восстанавливать эти настройки.
> *   Добавить плавные CSS-анимации при наведении на заголовок и карточки.
