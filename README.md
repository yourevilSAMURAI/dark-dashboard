# Dark Dashboard

Мой второй проект, созданный для отработки навыков работы с внешними API и создания серверной инфраструктуры. Это мрачный, минималистичный дашборд в стиле Gothic / Dark Wave, который собирает полезные данные в реальном времени.

## Посмотреть вживую:
Вы можете открыть дашборд по ссылке:
**[Открыть Dark Dashboard](https://yourevilsamurai.github.io/dark-dashboard/)**

## Что умеет проект:
*   **Погода в реальном времени**: Поиск погоды по любому городу через API `wttr.in`. Работает как по нажатию клавиши Enter, так и по кнопке «Найти». Описание погоды автоматически переводится на русский язык. *(Бонус: API настолько умен, что находит даже деревни с названиями вроде «Пельмени» или «Жопа», а если город не найден — показывает погоду по вашему IP).*
*   **Минималистичные иконки погоды**: Динамические символы (☀, ☾, ☁, ☂, ❄ и др.), которые меняются в зависимости от текущих условий.
*   **Курсы валют**: Загружает актуальные курсы (USD, EUR, CNY, GBP, JPY) к рублю с API Центрального Банка РФ. Показывает изменение курса за день в процентах с цветовой индикацией (зеленый — рост, красный — падение).
*   **Криптовалюты**: Выбор монеты (BTC, ETH, DOGE, SOL) из выпадающего списка. Отображает цену в долларах через API **CoinLore** и автоматически конвертирует её в рубли по актуальному курсу ЦБ РФ.
*   **Сохранение настроек (`localStorage`)**: Дашборд запоминает, какой город, валюту и криптовалюту вы выбрали. При перезагрузке страницы все ваши предпочтения восстанавливаются.
*   **Мировое время**: Показывает точное время в Москве, Лондоне и Токио, обновляясь каждую секунду.
*   **Живой статус системы**: Имитация «хакерского» монитора с реальным временем работы страницы (Uptime), потреблением памяти браузера (`performance.memory`), меняющимся пингом и уровнем угрозы.
*   **Готический интерфейс**: Плавные анимации при наведении на заголовок, адаптивная сетка и строгий стиль.

## Технологии и чему я научился:
*   **HTML5** (семантическая верстка, тег `datalist` для автодополнения).
*   **CSS3** (CSS Grid для сетки, Flexbox для карточек, медиа-запросы для адаптивности).
*   **JavaScript (Vanilla)**:
    *   Работа с **Fetch API** и асинхронным кодом (`async/await`).
    *   Парсинг данных в формате **JSON**.
    *   Управление **DOM** (динамическое изменение текста и классов).
    *   Использование таймеров **`setInterval`** для «живого» обновления данных.
    *   Обработка пользовательского ввода (события `keypress`, `click` и `change`).
    *   Работа с **`localStorage`** для сохранения пользовательских предпочтений.
*   **Бэкенд и Cloudflare Workers**: 
    *   Создал собственный **CORS-прокси** на Cloudflare Workers для обхода ограничений браузера при работе с внешними API.
    *   *Примечание:* В процессе тестирования было выявлено, что бесплатные лимиты CoinGecko слишком строгие для прямых запросов даже через прокси. Поэтому в финальной версии для криптовалют выбран API **CoinLore**, который не требует прокси и обеспечивает стабильную работу без ошибок `429 Too Many Requests`.
*   **Дизайн**: Строгий Gothic / Dark Wave с использованием готического шрифта Cinzel.
