# Dark Dashboard

Мой второй проект, созданный для отработки навыков работы с внешними API и создания серверной инфраструктуры. Это мрачный, минималистичный дашборд в стиле Gothic / Dark Wave, который собирает полезные данные в реальном времени.

## Посмотреть вживую:
Вы можете открыть дашборд по ссылке:
**[Открыть Dark Dashboard](https://yourevilsamurai.github.io/dark-dashboard/)**

## Что умеет проект:
*   **Погода в реальном времени**: Поиск погоды по любому городу (с автодополнением) через API `wttr.in`. Описание погоды автоматически переводится на русский язык.
*   **Курсы валют**: Загружает актуальные курсы валют (USD, EUR, CNY, GBP, JPY) к рублю с API Центрального Банка РФ. Показывает изменение курса за день в процентах с цветовой индикацией (зеленый — рост, красный — падение).
*   **Криптовалюты**: Выбор монеты (BTC, ETH, DOGE, SOL) из выпадающего списка. Отображает цену в долларах через API CoinGecko (через собственный прокси) и автоматически конвертирует её в рубли по актуальному курсу ЦБ.
*   **Мировое время**: Показывает точное время в Москве, Лондоне и Токио, обновляясь каждую секунду.
*   **Статус системы**: Имитация «хакерского» монитора с меняющимся пингом и уровнем угрозы.
*   **Готический интерфейс**: Плавные анимации при наведении на заголовок, адаптивная сетка и строгий стиль.

## Технологии и чему я научился:
*   **HTML5** (семантическая верстка)
*   **CSS3** (CSS Grid для сетки, Flexbox для карточек, медиа-запросы для адаптивности).
*   **JavaScript (Vanilla)**:
    *   Работа с **Fetch API** и асинхронным кодом (`async/await`).
    *   Парсинг данных в формате **JSON**.
    *   Управление **DOM** (динамическое изменение текста).
    *   Использование таймеров **`setInterval`** для «живого» обновления данных.
    *   Обработка пользовательского ввода (события `keypress` и `change`).
*   **Бэкенд и Cloudflare Workers**: 
    *   Создал собственный **CORS-прокси** на Cloudflare Workers для обхода ограничений браузера при работе с внешними API.
    *   *Примечание:* В процессе тестирования было выявлено, что бесплатные лимиты CoinGecko слишком строгие для прямых запросов даже через прокси. Поэтому в финальной версии для криптовалют выбран API **CoinLore**, который не требует прокси и обеспечивает стабильную работу без ошибок `429 Too Many Requests`.
*   **Дизайн**: Строгий Gothic / Dark Wave с использованием готического шрифта Cinzel.

## Структура проекта:
Код разделен на три файла для чистой архитектуры:
*   `index.html` — разметка карточек.
*   `style.css` — мрачный дизайн и сетка.
*   `script.js` — логика запросов к API и обновление времени.
